Gate 2+ prices come from the shipped estimator — $0.0026 per variable, ×1.32 for five cohorts, batch mode. A single drag moves fractions of a cent; the checkbox is where the money is. Both post to the same column, which is the point: correcting a group and deciding to pay for one settle in the same sum. Gate 1 is shown in judge calls, not dollars, on purpose. The estimator's STAGE_SHARES are ideal .06 · splitAssign .44 · gencde .28 · specgen .22 — they sum to 1.00 with no coherence line, so the judge is currently unpriced. Shipping this gate means adding a stage share for it. On the measured 5-cohort stack the judge ran 885 calls over 885 groups of ≥6 members. Search should be semantic, and it can be free. Group labels are machine-written, so a researcher searching for "cardiovascular" or "BMI" will not match them by string. Gate 1 has already embedded every variable — matching a query against group centroids is local, costs nothing, and is the same vector work the clustering just did. This gate decides what each concept maps to. Gate 3 then writes the recode for every source variable against that target — so a target you are not sure about becomes a recode you cannot trust. Sign-off here is the precondition for spec generation, which is why it is a gate and not a report. Layout adapted from CDEMapper (Wang et al., JAMIA 2025;32:1130–1139, doi:10.1093/jamia/ocaf064) — the ranked-candidate panel with score, collection and endorsement badges, question text, permissible values and a select action is theirs. Their reported coverage against NIH CDEs was 9.55%–43.75% across four domains, which is the empirical case for generating an element when nothing fits.
